Заряд Bluetooth-мыши, клавиатуры и наушников — в системном трее Windows

BattMon отображает заряд подключённых Bluetooth-устройств в системном трее рядом с часами и заранее предупреждает, когда их пора зарядить. Приложение реагирует на системные события Windows и не опрашивает устройства по таймеру.

Возможности BattMon

Выберите устройства для отслеживания один раз — BattMon будет работать в фоне и напомнит о низком заряде.

Bluetooth и Bluetooth LE
Следите за зарядом мышей, клавиатур, наушников и геймпадов — если уровень заряда доступен в Windows.
Иконка для каждого устройства
Настройте отдельную иконку для каждого устройства и выберите удобный вид: процент заряда или значок с батареей.
Предупреждения о низком заряде
BattMon напомнит о зарядке, когда уровень заряда опустится ниже заданного значения. Порог можно настроить для всех устройств сразу или для каждого отдельно.
Время последнего изменения
Проверяйте актуальность данных: в списке видно время последнего изменения заряда, а при наведении на иконку — точное время.
Светлая и тёмная тема
Приложение выглядит органично в светлой и тёмной теме Windows, а иконки в трее остаются заметными на панели задач.
Автозапуск
Включите автозапуск, чтобы BattMon всегда следил за зарядом в фоне. Закрыть окно можно безопасно: приложение продолжит работать.

Заряд с первого взгляда

Иконка состоит из двух частей: слева показан тип устройства, справа — индикатор батареи. Цвет батареи меняется от красного к зелёному в зависимости от уровня заряда. Контур иконки подстраивается под светлую или тёмную панель задач.

Как это работает

  • Заряд берётся из Windows. Приложение обновляет данные о заряде, когда Windows сообщает об изменениях.
  • Прямое чтение BLE включается отдельно. Для некоторых устройств доступно дополнительное прямое чтение заряда по Bluetooth Low Energy.
  • Без интернета. BattMon работает без интернета и хранит настройки только на компьютере.
  • Поддержка устройств с отдельным USB-приёмником 2,4 ГГц появится позже.

Вопросы

Windows предупреждает о потенциальной угрозе при запуске установщика. Это нормально?

Пока установщик не подписан цифровой подписью, Windows может показать предупреждение SmartScreen. Скачивайте установщик только с официальной страницы BattMon.

Нужны ли права администратора?

Нет. По умолчанию BattMon устанавливается только для текущего пользователя и не требует прав администратора. При необходимости в установщике можно выбрать установку для всех пользователей компьютера.

Почему у колонки или телефона не отображается заряд?

BattMon показывает уровень заряда, который устройство передаёт в Windows. Если Windows не получает эту информацию, приложение не сможет её отобразить.

Как удалить программу?

В поиске Windows напишите «Установка и удаление программ», найдите BattMon в списке и выберите «Удалить». Во время удаления установщик предложит сохранить или удалить настройки приложения
